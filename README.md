# Nuga Best Thika Road — latest homepage design

This is a **working static website** based on the most recently approved maroon-and-white visual reference. Open `index.html` in a browser, or upload the files **inside this folder** to your GitHub repository root and enable GitHub Pages.

Includes responsive Home, Therapy Services, Shop Products, Packages, Wellness Insights, About Us, Contact, search/filter for all 11 listed products and enquiry/booking flows. The new homepage has three featured products, two feature cards, a lifestyle/therapy section, four equipment highlights and an 11-product compact catalogue. All styling remains editable in `styles.css`, catalogue and WhatsApp number in `script.js`.

`DESIGN_REFERENCE.png` is an AI-generated **visual mockup only**. It is **not** the live website or a documentary photograph and is included for design comparison. The live website uses available reference photographs and explicitly labelled illustration assets; original high resolution product images are still needed to reach photographic sharpness. Do not present generated product images as verified genuine equipment.

Before publishing set `CONFIG.whatsappNumber` (international digits without +) in `script.js`. Check opening hours, prices and legal claims. E5 supplied prices differ; current provisional displayed figure KES 137,800. NM2500 price is missing (price on enquiry). The site prepares messages; it does not automatically send them or guarantee bookings.
